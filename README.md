# FINNI — Питомец Финни

**FINNI** — мобильное Android-приложение для знакомства детей 7–11 лет с основами финансовой грамотности через заботу о виртуальном питомце.

## Возможности демоверсии

* Виртуальный питомец и настройка его внешнего вида.
* Управление игровым балансом и планирование бюджета.
* Покупки за виртуальную валюту.
* Финансовые цели и накопления.
* Обучающие задания.
* Отслеживание прогресса и стадий развития питомца.

Доступность отдельных функций зависит от текущей версии демо.

## Технологии

* **Flutter** — разработка пользовательского интерфейса и приложения.
* **Dart** — язык программирования.
* **Android** — целевая мобильная платформа.
* **SharedPreferences** — локальное сохранение игрового состояния.

## Требования для запуска

Перед запуском проекта необходимо установить:

1. [Flutter SDK](https://docs.flutter.dev/get-started/install) — инструменты разработки Flutter.
2. [Android Studio](https://developer.android.com/studio) — Android SDK и инструменты для запуска приложения.
3. [Git](https://git-scm.com/downloads) — для получения исходного кода из репозитория.

После установки Flutter и Android SDK проверьте конфигурацию окружения командой:

```bash
flutter doctor
```

Следуйте рекомендациям команды, чтобы устранить ошибки настройки. Для запуска также потребуется подключённое Android-устройство с включённой отладкой по USB или запущенный Android-эмулятор.

## Получение исходного кода

Клонируйте репозиторий проекта:

```bash
git clone https://github.com/RANIK-code-jpg/Finni.git
```

Перейдите в каталог проекта:

```bash
cd Finni
```

## Установка зависимостей

В корневой папке проекта выполните:

```bash
flutter pub get
```

Команда загрузит зависимости, необходимые для работы приложения.

## Запуск приложения

Убедитесь, что Android-устройство подключено или эмулятор запущен. Затем выполните:

```bash
flutter devices
```

Команда покажет доступные устройства. После этого запустите приложение:

```bash
flutter run
```

Flutter соберёт приложение в режиме разработки и запустит его на выбранном устройстве.

## Сборка APK

Для создания релизной версии приложения выполните:

```bash
flutter build apk --release
```

После успешной сборки APK появится по следующему пути:

`build/app/outputs/flutter-apk/app-release.apk`

Полученный APK можно перенести на совместимое Android-устройство и установить для проверки работы приложения.

Также доступна готовая релизная сборка:
